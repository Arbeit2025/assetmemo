# かんたん資産メモ（assetmemo）

資産の内訳を手入力で記録して、合計と割合を眺めるためのシンプルなメモです。

**大切な前提**：このツールは手入力専用です。株価や暗号資産の価格を自動取得することはしませんし、売買などの取引機能もありません。金額は、残高を確認したときに自分で更新してください。

## 使い方

- **登録**：名前・カテゴリ（現金／預金／株式／投資信託／暗号資産／その他）・金額（円）を入力します。
- **内訳表示**：資産の合計と、カテゴリごとの合計・割合（%）がバーグラフで表示されます。
- **削除**：各資産の「削除」ボタンで消せます（確認ダイアログ付き）。

データは SQLite に保存されます。DB のパスは環境変数 `ASSETMEMO_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- 価格の自動取得はしないため、株式や暗号資産の金額は入力した時点のままです。時価を知りたい場合は各証券会社・取引所で確認してください。
- 編集機能はありません（金額を直す場合は削除して登録し直してください）。
- 履歴や推移グラフはありません。「いまの内訳」を記録するだけのツールです。
- ログイン機能はありません。金額のような機微な情報を入れる場合は、公開範囲に注意してください。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
